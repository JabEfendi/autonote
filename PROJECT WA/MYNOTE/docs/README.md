# MYNOTE Documentation

This directory records the implementation history, decisions, verification results, limitations, and follow-up work for MYNOTE.

## Documentation Rules

Every completed development task must have a Markdown entry containing:

- Date and objective.
- Scope and files or modules changed.
- Explanation of the implementation.
- Verification commands and results.
- Known limitations or risks.
- Next PRs or follow-up tasks.

Do not put credentials, session data, environment values, raw WhatsApp messages, full phone numbers, or generated personal reports in this directory.
